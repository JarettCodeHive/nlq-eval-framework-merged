# Logistics — Category 6: A Correct Value Is Reported as Missing (2 questions)

Two inventory-breakdown questions get three of four region values exactly
right, and then explicitly state that the fourth value is missing or
unconfirmed — even though that same figure appears correctly elsewhere in
the same response.

## Example

**Questions:** hardware inventory and supplies inventory, both broken
down by warehouse region (4 regions each).
**Pattern:** LATAM, EU, and APAC match the expected answer exactly in
both answers. For the fourth region (NA), the response states the value
"was not present in the provided breakdown" / "cannot confirm" — even
though the correct NA figure is present elsewhere in the same response's
broader all-category breakdown.

## The problem

The response contradicts its own data: it computes the right number for
a value, states elsewhere that the number isn't available for that
specific breakdown, and the one place that number needed to be attached
to its label is exactly where it says the number is missing.
