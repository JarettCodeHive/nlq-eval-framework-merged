# Logistics — Category 1: Percentage-Change Figure Omitted (9 questions)

The "how did X change from Q1 2026 to Q2 2026" question family expects
five values together: the Q1 total, the Q2 total, the absolute change,
the percentage change, and a direction word. In 9 of these questions, the
answer states the Q1/Q2 values and the absolute change correctly, and
conveys the direction correctly in prose ("fell sharply") — but never
states the percentage-change number anywhere in the response.

## Example

**Question:** NA-region order value change, Q1 2026 → Q2 2026.
**Expected:** `72296800.92 | 3492949.09 | -68803851.83 | -95.17 | down`
**Answer:** "...dropping from $72,296,800.92 ... to $3,492,949.09 ..., a
change of -$68,803,851.83" — three of the five values are exactly right,
but `-95.17` appears nowhere in the text, even though the response clearly
had the number available to compute the first three figures.

## The problem

For this question shape, the percentage-change figure is consistently
left out, even when every other number in the same 5-part answer is
present and correct. Five of these nine questions also have a second,
independent issue (see Category 2) with the absolute-change figure, so
the missing percentage alone is enough to account for the gap in every
one of them.
