# Sales — Category 3: Percentage-Change Figure Never Stated (6 questions)

Every "how did X change from Q1 2026 to Q2 2026" question's expected
answer is a 5-part record: Q1 total, Q2 total, absolute change,
percentage change, and a direction word. In every failure in this
category, the response states Q1, Q2, and the absolute dollar change
correctly — but never states the percentage anywhere in the text, even
though the question itself never explicitly asked for one.

## Examples

- Expected `... | -90.65 | down`. Response: "...a drop of $2,158,521.67..."
  — no percentage anywhere in roughly 250 words of prose.
- One rephrase of the same underlying question states the decline in
  words only ("closed less... a decline of $2,158,521.67") and is judged
  factually correct on its own terms — the number is simply never part of
  how this question gets answered.
