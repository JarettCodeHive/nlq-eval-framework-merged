# Sales — Category 4: List Tail Compressed Into a Range Instead of Enumerated (1 question)

"Which reps in the Central territory missed quota... and by how much?"
expects 8 individually labelled shortfall amounts. The response names the
first 5 reps with exact figures, then summarizes the remaining three as
"three others... in the roughly $63,000 to $96,000 range" — the three
correct dollar figures are never written down individually, only
described as falling in a range.

Affected: `SALES-RG-12-V01`.
