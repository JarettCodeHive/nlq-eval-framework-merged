# Project Management — Category 6: A Response Contradicts Its Own Breakdown (1 question)

One question's headline figure doesn't match the detailed breakdown given
right below it, in the same answer.

## What's happening

**Question:** "What percentage of milestones for planning projects have
been completed?" Expected `47.44`. The headline figure in the response is
`100%`. But the same response's own detailed breakdown reports 111
Completed / 123 Not Completed out of 234 total milestones —
`111 / 234 = 47.44%`, matching the expected answer almost exactly. The
response even flags this itself, noting the headline figure "appears
inconsistent with the detailed completion-status breakdown... a data
processing or aggregation issue rather than true completion performance."

## The problem

The detailed breakdown is right; the headline aggregate figure in the
same response is wrong — an internal inconsistency within one answer,
not a disagreement between the answer and the ground truth about what
the real numbers are.
